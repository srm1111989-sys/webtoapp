# Dev.to / Medium / Hashnode Daily Publishing Plan (t127, 2026-07-29)

Goal: daily developer-platform articles that (a) rank for long-tail queries on high-DA
domains, (b) feed the LLM/ChatGPT answer set (dev.to is heavily crawled by AI models),
(c) drive referral signups. One article/day, ~15 minutes each using the templates below.

## Platform rules (important)

- **dev.to** — primary. DA 90+, indexed fast, LLMs cite it. Use the `canonical_url`
  front-matter field pointing at our matching blog post when one exists (avoids
  duplicate-content penalty; equity flows to websitetoapp.app).
- **Medium** — republish the same article 2–3 days later via "import story" (sets
  canonical automatically). Don't write separately.
- **Hashnode** — same, set original-article URL in settings.
- Every article: 1 contextual link to websitetoapp.app in the intro or conclusion +
  1 link to a specific deep page (alternatives/convert/blog) — never more than 3 links.
- Tags on dev.to: pick 4 from `webdev, android, javascript, tutorial, beginners,
  productivity, mobile, windows`.
- NEVER publish the same title on two platforms the same day. Existing accounts and
  Edge profiles: see IndexFlow CLAUDE.md backlink section (edge-devto-profile,
  edge-hashnode-profile).
