## Conversion Tracking Setup

### Required Actions in Google Ads:

1. **Primary Conversion: Purchase/Payment**
   - Track when user completes payment (Stripe/Razorpay success)
   - Conversion value: $30 (Android) or $24 (Desktop)
   - Conversion window: 30 days

2. **Secondary Conversion: Registration**
   - Track when user creates account
   - Use for "Maximize Conversions" optimization
   - Conversion window: 7 days

3. **Micro Conversions (observation only):**
   - Started app wizard
   - Reached pricing page
   - Downloaded free APK

### Google Tag Implementation:

Add to your frontend `index.html` or via Google Tag Manager:

```html
<!-- Google Ads Conversion Tracking -->
<script async src="https://www.googletagmanager.com/gtag/js?id=AW-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'AW-XXXXXXXXXX');
</script>
```

Fire conversion on payment success page:
```javascript
// On payment success (after Stripe/Razorpay callback)
gtag('event', 'conversion', {
  'send_to': 'AW-XXXXXXXXXX/CONVERSION_LABEL',
  'value': 30.0,
  'currency': 'USD',
  'transaction_id': orderId
});
```

Fire registration conversion:
```javascript
// On successful registration
gtag('event', 'conversion', {
  'send_to': 'AW-XXXXXXXXXX/REGISTRATION_LABEL',
  'value': 0,
  'currency': 'USD'
});
```

## Google Ads Account Setup Steps

### Step 1: Create Google Ads Account
1. Go to ads.google.com
2. Sign in with your Google account
3. Choose "Switch to Expert Mode" (bottom of page - IMPORTANT)
4. Select "Create campaign without a goal's guidance"
5. Complete billing setup

### Step 2: Set Up Conversion Tracking
1. Go to Tools > Conversions
2. Click "+ New conversion action"
3. Select "Website"
4. Enter https://websitetoapp.app/
5. Set up two conversions:
   - "Purchase" (primary, $30 value)
   - "Registration" (secondary, $0 value)
6. Install the Google tag on your site

### Step 3: Create Campaign 1 (High-Intent)
1. Click "+ New Campaign"
2. Objective: Sales (or create without guidance)
3. Type: Search
4. Networks: Google Search only (uncheck Display Network)
5. Locations: All countries (or start with US, UK, India, Canada, Australia)
6. Language: English
7. Budget: $15/day
8. Bidding: Maximize Conversions
9. Create ad groups and ads as outlined above

### Step 4: Add Extensions
1. Sitelinks (as listed above)
2. Callouts (as listed above)
3. Structured snippets
4. Price extension ($30 one-time)

### Step 5: Set Negative Keywords
Add the negative keyword list to all campaigns (see above)

### Step 6: Launch & Monitor
- Check daily for first week
- Pause keywords with high spend + no conversions after 50 clicks
- Add search terms as negative keywords weekly
