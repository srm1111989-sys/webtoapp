## 📞 Support & Troubleshooting

### If Meta Tags Don't Show:
1. Clear browser cache
2. Hard refresh (Ctrl+Shift+R)
3. Check view source (Ctrl+U)
4. Verify container is running: `docker compose ps frontend`

### If Blog Post 404s:
1. Check React Router configuration
2. Verify blogPosts.ts has correct slug
3. Check browser console for errors
4. Verify build included latest changes

### If Search Console Submission Fails:
1. Verify URL is accessible publicly
2. Check robots.txt isn't blocking
3. Ensure sitemap.xml is accessible
4. Wait 1 hour and retry (rate limit)
