## 🔍 Schema Markup

**Choose one based on content type:**

### Option 1: Article Schema
```json
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "[Article Title]",
  "author": {
    "@type": "Organization",
    "name": "WebsiteToApp"
  },
  "datePublished": "2026-XX-XX",
  "image": "[featured-image-url]"
}
```

### Option 2: HowTo Schema
```json
{
  "@context": "https://schema.org",
  "@type": "HowTo",
  "name": "[How to Title]",
  "step": [
    {
      "@type": "HowToStep",
      "name": "Step 1 Name",
      "text": "Step 1 description"
    }
  ]
}
```

### Option 3: FAQ Schema
```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "Question text?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Answer text"
      }
    }
  ]
}
```

**Add schema to bottom of post before `</body>` tag**

## 📊 Word Count Guidelines

**By Content Type:**
- **Pillar Posts:** 2,500-3,500 words
- **How-To Guides:** 2,000-2,500 words
- **Comparison Posts:** 2,000-3,000 words
- **List Posts:** 1,500-2,000 words
- **Case Studies:** 1,000-1,500 words
- **News/Updates:** 500-1,000 words

**Target for most posts: 2,000-2,500 words**

---

## 💡 Quick Tips

1. **Write for humans first, search engines second**
2. **Answer the searcher's question completely**
3. **Use simple language (8th-grade reading level)**
4. **Break up text with headers, bullets, images**
5. **Add examples and screenshots**
6. **Link to your other content**
7. **End with a clear call-to-action**
8. **Proofread before publishing**

---

## 🎯 Content Quality Standards

**Every post should:**
- ✅ Solve a specific problem
- ✅ Provide actionable advice
- ✅ Include real examples
- ✅ Be better than competitors
- ✅ Build trust and authority
- ✅ Encourage conversion (CTA)

**Avoid:**
- ❌ Thin content (<1,500 words)
- ❌ Keyword stuffing
- ❌ Duplicate content
- ❌ Clickbait titles
- ❌ No value-add
- ❌ Too promotional
