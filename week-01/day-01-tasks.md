### Task 2: Set Up Google Search Console (30 min)
**Priority:** 🔥 CRITICAL

#### Step 2.1: Create Search Console Account
- [ ] Go to: https://search.google.com/search-console
- [ ] Sign in with Google account
- [ ] Click "Add Property"
- [ ] Enter: `websitetoapp.app`

#### Step 2.2: Verify Ownership
Choose ONE verification method:

**Option A: HTML File Upload (Easiest)**
1. Download verification HTML file from Search Console
2. Upload to: `websitetoapp.app/google-verification.html`
3. Click "Verify" in Search Console

**Option B: HTML Tag**
1. Copy meta tag from Search Console
2. Add to `<head>` section of homepage
3. Click "Verify"

**Option C: DNS Record**
1. Copy TXT record from Search Console
2. Add to domain DNS settings
3. Click "Verify" (may take 24 hours)

- [ ] Verification complete ✅

**Claude Prompt:**
```
"Generate the HTML meta tag code for Google Search Console verification for websitetoapp.app"
```

**Why:** Search Console shows you how Google sees your site. Essential for tracking rankings.
